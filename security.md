# Security Policy

## Supported Versions

The following table lists which versions of this project are currently being supported with security updates:

| Version | Supported          |
|---------|--------------------|
| 1.0     | ✅                 |
| 0.2     | ❌ (no longer maintained) |

If you're using an older version, please upgrade to the latest version to benefit from security patches.

---

## Reporting a Vulnerability

If you discover a security vulnerability in this project, **please do not open a public issue**. Instead, follow the steps below:

1. **Email the Maintainer**  
   Send a detailed report to: [handyreels@example.com]  
   Include:
   - A description of the vulnerability  
   - Steps to reproduce  
   - Any proof-of-concept (PoC) code  
   - The potential impact

2. **Response Timeline**  
   We aim to respond within **3 business days**.  
   After confirming the issue, we will take appropriate action and provide a timeline for a fix.

3. **Disclosure**  
   We follow **responsible disclosure practices**. Once a fix is available and deployed, we will credit the reporter (if desired) and publish a summary in the release notes.

---

## Security Best Practices

If you're using this project in production, we recommend:
- Always using the latest release  
- Avoiding hardcoded secrets or tokens  
- Running the code in a sandboxed or virtualized environment (e.g., Docker, venv)  
- Keeping dependencies up to date with tools like `pip-audit` or `safety`
